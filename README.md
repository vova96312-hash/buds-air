# Buds Air

Приложение для наушников **realme / OPPO / OnePlus** (сделано под realme Buds Air 8) в стиле «жидкого стекла».

- заряд левого и правого наушника и кейса;
- шумоподавление: выкл / шумодав / прозрачность;
- игровой режим, подключение к двум устройствам, объёмный звук (если модель умеет);
- поиск наушников звуком;
- настройка жестов отдельно для левого и правого;
- эквалайзер, записывается прямо в наушники;
- **виджет на рабочий стол**: заряд и кнопки режимов;
- **плитка в шторке**: нажатие переключает режим шумоподавления;
- журнал обмена с наушниками для отладки.

Набор функций приложение узнаёт у самих наушников при подключении, как это делает realme Link.

## Сборка
APK собирается автоматически через GitHub Actions (`.github/workflows/build.yml`) и появляется в Releases.
